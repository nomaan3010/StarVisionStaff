BUILD WITHOUT ANDROID STUDIO (free, uses GitHub online)

1. Make a free account at github.com and create a new repository (name: StarVisionStaff).
2. Upload everything from this folder to the repository (Add file > Upload files).
   Also upload your logo and name it exactly: logo.png
3. Make sure the file .github/workflows/build.yml exists in the repository.
   If the upload skipped it: Add file > Create new file, name it .github/workflows/build.yml and paste its contents.
4. Open the Actions tab > Build APK > Run workflow. Wait about 5-10 minutes.
5. Open the finished run, scroll to Artifacts, download StarVisionStaff-APK (a zip containing app-debug.apk).
6. Send app-debug.apk to staff on WhatsApp and install.
